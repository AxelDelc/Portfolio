À propos du projet

Ce projet fait partie de ceux sur lesquels j'ai travaillé pendant mon stage chez Astek, en fin de première année à MyDigitalSchool. Ma mission : refaire la page d'accueil du site SFR avec WordPress, pour que SFR puisse juger si ce CMS était adapté à la refonte de son site.

Les thèmes proposés par WordPress ne permettent pas de reproduire une page aussi précise. J'ai donc créé un thème personnalisé. Ces thèmes reposent sur du HTML, du CSS et du JavaScript classiques, auxquels on ajoute du PHP directement dans le HTML pour rendre les éléments voulus modifiables dans le customizer de WordPress.

Objectifs

  • Recréer l'interface utilisateur de SFR
  • Découvrir les thèmes personnalisés de WordPress
  • Voir si WordPress peut être un CMS adapté pour refaire intégralement le site de SFR

Défis rencontrés

Le plus dur a été d'apprendre une nouvelle bibliothèque PHP, car WordPress utilise des hooks et des API PHP qui lui sont propres. Ce projet m'a permis de progresser en HTML et CSS, et m'a appris une nouvelle manière de développer en PHP, ce qui l'a rendu très intéressant.

Stack technique

Front-end

HTML5, CSS3, customizer WordPress

Back-end

PHP avec la documentation WordPress

Résultats et apprentissages

Ce projet m'a permis de renforcer mes compétences en HTML et CSS et de découvrir le développement de thèmes personnalisés sous WordPress. J'ai appris à utiliser le PHP spécifique à WordPress, notamment les hooks et le customizer, pour rendre les contenus dynamiques, et à m'adapter rapidement à de nouvelles contraintes techniques.
